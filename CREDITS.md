# Asset credits

This repository intentionally contains only the Godot project code, scenes, configuration,
and documentation. It does **not** contain third-party models, textures, UI images, music,
Godot cache files, or exported APKs. Download the required assets yourself from the sources
below and place them in the project's local `assets/` folder using the paths referred to by
the scripts.

## Game engine

- **Godot Engine 4** — game engine used by this project.
  - https://godotengine.org/
  - License: MIT.

## Environment

- **Abandoned House** by El Bolillo Duro — the abandoned-house scene, furniture, textures,
  and source props used for the playable test map.
  - https://elbolilloduro.itch.io/abandoned-house
  - Downloaded locally into: `assets/abandoned_house/`
  - License/usage terms: see the asset page before distributing a build.

## Characters and animations

- **KayKit Adventurers** by Kay Lousberg — Knight, Mage, Rogue, Rogue Hooded, Ranger,
  and Barbarian player character models.
  - https://kaylousberg.itch.io/kaykit-adventurers
  - Downloaded locally into: `assets/kaykit_reference/`
  - License: CC0 (as stated by the creator).

- **KayKit Character Animations** by Kay Lousberg — the compatible humanoid idle, walking,
  running, and general animation library used by the characters.
  - https://kaylousberg.itch.io/kaykit-character-animations
  - Downloaded locally into: `assets/kaykit_reference/`
  - License: CC0 (as stated by the creator).

## User interface

- **Kenney Mobile Controls** — mobile joystick and touch-control graphics used as the
  reference/source for the landscape touch UI.
  - https://kenney.nl/assets/mobile-controls
  - License: CC0.

- **Kenney Fantasy UI Borders** — fantasy panel/border artwork used as the reference/source
  for the game information and interface style.
  - https://kenney.nl/assets/fantasy-ui-borders
  - License: CC0.

## Background music

## Notes for contributors

- Do not commit downloaded asset files or exported APKs to this repository.
- Preserve these credits in any distributed build or project documentation.
- Before public release, re-check each source page for its current license and attribution
  requirements.
